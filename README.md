## Overview
클리오 홈페이지를 리뉴얼 하였습니다. 회사의 비전, 사업 성과를 소비자들이 한 눈에 알 수 있도록 하는 것이 목표였습니다. 

## Features  
- Next.js를 이용한 홈페이지 구성
- GSAP, Swiper Library를 이용하여 동적인 웹 구현
- Firebase를 통한 로그인 기능 구현

## Technologies  
- **Design** : Figam, Adobe Photoshop
- **Frontend**: Next.js, Sass, GSAP, Swiper
- **Backend**: Firebase
